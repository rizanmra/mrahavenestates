# MRA Haven Estates

Custom Next.js website for MRA Haven Estates — sales, lettings, removals and valuations across Bradford and West Yorkshire.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

- **Home** — cinematic hero video, property search, services, valuation CTA, testimonials
- **Sales / Lettings / Removal Services** — service pages with booking CTAs
- **Free Valuation** — valuation request form
- **Properties** — buy/rent listings with search filters
- **Contact** — enquiry form with office details

## Design

- Navy (`#0B1E33`) and gold (`#C4A47C`) colour theme from the original Wix site
- Serif headings (Cormorant Garamond) + sans body (Outfit)
- Hero video: replace `src/data/site.ts` → `heroVideo.src` with your custom cinematic tour
